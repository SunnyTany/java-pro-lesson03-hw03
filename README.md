# Temperature Converter Application (Modular Version)

JAVA: Консольный конвертер температур, разделенный на логические модули для обеспечения чистоты кода и легкости масштабирования.

## Архитектура проекта

Проект разделен на 4 основных класса (принцип Single Responsibility):

1.  **`CalculationEngine`**: Математическое ядро. Содержит формулы конвертации и константы физических пределов (абсолютный ноль).
2.  **`HistoryManager`**: Слой данных. Управляет списком истории через `LinkedList`, обеспечивая быстрые операции добавления и удаления.
3.  **`MenuHandler`**: Слой интерфейса. Отвечает за взаимодействие с пользователем и текстовое меню.
4.  **`TemperatureConverter`**: Контроллер. Главный класс, который связывает все компоненты воедино.

## Функционал

- **Конвертация**: Celsius ↔ Fahrenheit, Celsius ↔ Kelvin.
- **Валидация**: Проверка на ввод значений ниже абсолютного нуля.
- **История**: Автоматическое сохранение последних 100 операций.
- **Очистка**: Возможность мгновенно удалить всю историю через меню.

## Технические особенности

- **LinkedList**: Выбран для оптимизации работы с очередью истории ($O(1)$ при удалении старых записей).
- **Разделение логики**: Легко изменить формулы или язык интерфейса, редактируя только один соответствующий класс.
