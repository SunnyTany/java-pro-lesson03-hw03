# Temperature Converter Application

Консольний додаток на Java для конвертації температури між шкалами **Цельсія**, **Фаренгейта** та **Кельвіна**. 
Програма має вбудовану валідацію даних, збереження історії операцій та використовує оптимізовані структури даних.

## Можливості

- **Конвертація між різними одиницями**: Підтримка Цельсія, Фаренгейта та Кельвіна.
- **Фізична валідація**: Заборона введення значень нижче **абсолютного нуля** (0 K, -273.15 °C, -459.67 °F).
- **Відстеження історії**: Зберігання останніх 100 операцій у списку `LinkedList`.
- **Керування історією**: Можливість перегляду минулих конвертацій або повного очищення списку.
- **Обробка помилок**: Захист від некоректного вибору в меню та нечислових значень.

## Як запустити

1.  **Склонуйте проект** або скопіюйте файл `Converter.java`.
2.  **Скомпілюйте** код:
    ```bash
    javac app/Converter.java
    ```
3.  **Запустіть** програму:
    ```bash
    java app.Converter
    ```

## Використання

Дотримуйтесь інструкцій у меню:
1. Оберіть тип конвертації (1-4).
2. Введіть значення температури.
3. Використовуйте пункт `5` для перегляду історії.
4. Використовуйте пункт `6` для повного видалення історії.
5. Введіть `0` для виходу з програми.
